HAZEHUB ACCOUNTS
================================================================

Sign in with a Scouter ID plus the shared team password. The ID decides
what the account can do. All of the accounts below are created
automatically the first time the server starts, so there is nothing to
set up by hand.

Shared team password:  HazeRain!
   Everyone types this, whatever their role. Change it before a real
   event: it is published in this repository. Set HAZEHUB_TEAM_PASSWORD
   on the server (backend/.env locally, or the Render dashboard).

There is NO separate picklist password any more. The old
"PickListSTRAT" gate is gone; picklists are controlled by account role
instead, so scouts can build their own lists without being let into
anything else.

----------------------------------------------------------------
ACCOUNTS
----------------------------------------------------------------

  Scouter ID    Role        What it can do
  ----------    --------    ------------------------------------
  admin         Admin       Everything. Event control, match flow,
                            betting settings, film, and changing
                            other people's roles.

  strategy      Strategy    Everything an admin can do except
                            changing roles. All analysis screens.
                            Its picklists outrank scouter lists
                            during the picklist meeting.

  picklist      Picklist    The shared screen for a picklist
                            meeting. Teams and picklists only.
                            It cannot advance the match, place a
                            bet, or submit scouting, so a mis-tap
                            on a projector cannot break anything.

  1, 2, 3       Scouter     Demo scouting accounts. Scout matches,
                            bet, and build their own picklists.

Anyone else who signs in gets a plain Scouter account created for
them on the spot. That is how the other ~60 people get in: they type
their own ID and the shared password.

----------------------------------------------------------------
CHANGING SOMEONE'S ROLE
----------------------------------------------------------------

Sign in as admin, then Admin > Dashboard, or call the API directly:

  POST /api/admin/scouters/<scouter id>/role   {"role": "strategy"}

Valid roles: scouter, strategy, admin, picklist.
Admin only. Strategy accounts cannot promote anyone, and an admin
cannot demote themselves, so the team can never lock itself out.

To have extra accounts start with a role automatically, set these on
the server (comma separated, case insensitive):

  HAZEHUB_ADMIN_IDS=admin,arjun
  HAZEHUB_STRATEGY_IDS=strategy,lead1,lead2
  HAZEHUB_PICKLIST_IDS=picklist,meeting-tv

----------------------------------------------------------------
BEFORE A REAL EVENT
----------------------------------------------------------------

1. Change HAZEHUB_TEAM_PASSWORD from HazeRain!.
2. Set HAZEHUB_SECRET to a long random string. It signs the login
   tokens; changing it signs everyone out, so do it beforehand and
   not mid-event.
3. Be aware of what the shared password means: anyone who knows it
   can sign in as "strategy" or "admin" and get those powers, because
   there is one password for the whole team. If that matters to you,
   rename those accounts to IDs your scouts will not guess (via
   HAZEHUB_ADMIN_IDS / HAZEHUB_STRATEGY_IDS above) or ask for
   per-role passwords to be added.
4. This file is committed to the repository. Do not put a real
   password in it.
